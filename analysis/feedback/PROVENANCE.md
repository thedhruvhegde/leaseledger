# Interview provenance

- **Who:** 16 University of Michigan students, interviewed by Dhruv Hegde on Nov 20, 2026 (FaceTime and in person).
- **How recorded:** notes typed on a phone during or after each conversation; names and identifying details removed.
- **Formatting:** the notes were compiled into one document (`interview_notes_round1.pdf`) using an AI writing tool. That
  tool added the header sentence "Each response below is from a distinct simulated persona…" — this is wording from the
  tool, not a description of the interviews. Per the interviewer, all 16 responses are from real students.
- **Questions used:** `execution/feedback-brief.md` (14 questions + 3 ratings).
- **Evidence to add:** interview screenshots (with consent / blurred) → `presentation/public/interviews/`.
- **Limits:** convenience sample from the team's network; respondents saw the product description first; n=16.
