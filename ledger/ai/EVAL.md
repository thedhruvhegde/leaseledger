# AI parsing evaluation (measured 2026-11-20)

Generated by `python3 -m tests.ai.run_eval [--live]`. Labeled set: `tests/ai/eval_data.py` — 18 schedule strings (40 gold events) and 8 fictional listing texts, all **synthetic test data written by us** (not real listings or people).

**Caveat:** the rule parsers were developed against the main set, so its rule scores are optimistic. The HELD-OUT set (6 schedules, 3 listings) was written after tuning and the parsers were not changed in response to it; treat those numbers as the honest estimate. Both sets are small, so one error moves a score by several points.

Matching: a predicted event matches a gold event with the same building and overlapping days. Field precision = correct / predicted (unmatched predictions count against every field); recall = correct / gold-stated. Fields the text does not state are not scored, except listing fields labeled `None` (must not be extracted). Quotes are verified in code, so a fabricated quote cannot reach the output.
